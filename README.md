## 📖 Overview

This is my personal portfolio website built to showcase my skills in **Data Analytics, Web Development, and Problem Solving**.

It highlights my projects, dashboards, and experience as a **Data Analytics Trainer**, along with my journey in coding and content creation through my YouTube channel **Legend Coders**.

## 🛠️ Tech Stack

* ⚛️ React.js (Vite)
* 🎨 Tailwind CSS
* 📜 JavaScript
* 🚀 Vercel (Deployment)

## ✨ Features

* 👨‍💻 Clean and modern UI
* 📊 Project showcase (Data Analytics + Development)
* 📈 Dashboard previews
* 📱 Fully responsive design
* 🔗 Social media integration
* ⚡ Fast performance (Vite powered)
